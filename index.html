Agentic AI for regression testing

An AI agent that explores the application on its own and drafts regression test cases.

Problem
Writing regression coverage for a large app takes a lot of manual effort.
Approach
An agent navigates the app, learns its flows and proposes test cases for QA to review.

02

Common RBAC test utility

One shared layer to verify who can see and do what, reused across modules.

Problem
Each module tested role permissions its own way, with duplicated checks.
Approach
A reusable utility that takes a role and expected access and runs the checks the same way everywhere.
RBACCypressPlaywright
03

Test data pre-setup utility

Creates the data each test needs before it runs, so tests don't depend on each other.

Problem
Tests failed when the data they needed was missing or changed by other tests.
Approach
A pre-setup step that builds each test's data dependencies first, so suites run in any order.
